# LastRecall 已知问题与测试

| 項目 | 狀態 | 說明 |
| ---- | ---- | ---- |
| 敵人強度 | 🛠 需要平衡 | 高階敵人的傷害與血量仍需配合 Raid 風險調整。 |

## 目前表現穩定的項目

- Raid 進入、區域之間移動、撤離、死亡返回與掉落物回收都能運作。
- 從 Raid 返回主世界後無法移動或開啟選單的問題已修正。
- 加油站商店的多人進出已通過測試；來回後敵人、物資、撤離與死亡流程維持正常。
- M1911 手持位置偏移、左右翻轉、空倉聲過快重複與自製槍聲播放問題已完成相關測試。
- 無菌繃帶可以正常回血，醫療物品也不會再異常中斷。

詳細修正紀錄請見 [[30 - Release/Resolved Issues|已修正問題]]。
