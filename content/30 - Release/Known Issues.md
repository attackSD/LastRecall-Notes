# LastRecall 已知問題與測試

## 已知問題

| 問題 | 狀態 | 說明 |
| --- | --- | --- |
| 客戶端無法重新裝彈 | 🔴 待修正 | 客戶端按下 `R` 沒有反應，無法重新裝彈。 |
| 進入地圖後死亡無法返回 | 🔴 待修正 | 玩家進入地圖後死亡，無法正常返回。 |
| 進入地圖後地圖消失 | 🔴 待修正 | 進入地圖後，地圖會直接消失。 |
| 重裝後子彈不會扣除 | 🔴 待修正 | 重裝完成後，子彈數量沒有正確扣除。 |
| 敵人強度尚未平衡 | 🛠 待調整 | 高階敵人可能直接擊倒 100 血玩家，且敵人血量偏高。 |
| 箱內物資與交易價格尚未平衡 | 🛠 待調整 | 箱子內容與回收商商品需要配合突襲風險重新調整。 |

## 待測試項目

以下功能在單人已可使用，但多人流程尚未完成驗證：

- 傳送機、隊伍準備與出發倒數。
- 撤離點與死亡後物品回收。
- 箱子搜尋與現有物品／補給。

補給與醫療物品也需要在最新機制下重新測試。

## 目前沒有已知問題

- 玩家據點可正常使用。
- 加油站可正常進出。
- 彈藥／彈匣與交易貨幣餘額可正常顯示。
- 文字顯示目前沒有已知問題；未來會加入繁體／簡體中文切換。
