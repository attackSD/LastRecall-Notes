# LastRecall Project Notes

這是 LastRecall 專案的獨立知識庫，用來整理設計決策、raid 地圖流程、物品系統、技術筆記與待辦事項。

## 開始記錄

直接在 `content` 資料夾建立 Markdown 檔案。Quartz 會在網站中自動建立連結、搜尋、標籤、反向連結與知識圖譜。

## 建議的分類

- `000 - Project`：設計方向、系統規格與規劃
- `100 - Gameplay`：raid、撤離、戰利品與玩家流程
- `200 - Technical`：tModLoader、SubworldLibrary、網路與儲存
- `300 - Archive`：完成或過期的記錄
