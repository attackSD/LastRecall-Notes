# LastRecall 目前進度

## 正在進行

**Desert Wasteland 沙漠荒地地圖建置**仍在非常前期。地形、探索路線、建築／場景與氛圍都正在從原型開始建立。

## 功能概覽

| 狀態 | 功能 | 目前情況 |
| --- | --- | --- |
| ✅ | 玩家據點 | 可正常使用，目前沒有已知問題。 |
| ✅ | 客戶端裝填 | 最新多人測試中可正常重新裝填，子彈也會正常扣除。 |
| ✅ | 進入地圖 | 最新多人測試可成功進入地圖；先前地圖消失問題本次沒有重現。 |
| 🛠 | 加油站進出 | 單人可正常進出；多人測試中，進入加油站的傳送門沒有生成。 |
| 🛠 | 撤離與死亡回收 | 單人正常；多人測試中撤離點沒有生成，死亡後重生倒計時會卡在最後一秒。 |
| ✅ | 資訊顯示 | 彈藥／彈匣與交易貨幣餘額可正常顯示。 |

| 🛠 | 搜刮箱子 | 可搜尋且會逐步揭露內容；仍缺音效與物資平衡。 |
| 🛠 | 回收商交易 | 收購與購買正常；商品內容與價格仍需平衡。 |
| 🛠 | 現有槍械 | 單人功能正常，但素材與音效品質不一致。 |
| 🔍 | 補給與醫療物品 | 最近機制更新後尚未重新測試。 |

## 目前優先事項

1. 修正多人撤離點、加油站傳送門與死亡後重生的阻斷問題。
2. 完成沙漠荒地的基礎地圖建置。
3. 平衡敵人、箱內物資與回收商商品價格。
4. 改善傳送機的地圖選擇介面與方塊材質。
5. 安排其餘多人流程測試。

## 後續方向

- 將敵人生成與撤離點改為更容易調整的設定方式。
- 建置加油站室內地圖，並讓未來地圖能有多個撤離點。
- 重製槍械與物品素材；槍械改裝將改變外觀。
- 新增繁體／簡體中文切換選項。
