# LastRecall 目前進度

## 正在進行

**Desert Wasteland 沙漠荒地地圖建置**仍在非常前期。地形、探索路線、建築／場景與氛圍都正在從原型開始建立。

## 功能概覽

| 狀態 | 功能 | 目前情況 |
| --- | --- | --- |
| ✅ | 玩家據點 | 可正常使用，目前沒有已知問題。 |
| ✅ | 客戶端裝填 | 多人測試中可正常重新裝填，子彈也會正常扣除。 |
| ✅ | 進入地圖 | 多人測試可成功進入地圖；先前地圖消失問題本次沒有重現。 |
| 🛠 | 加油站進出 | 傳送門已正常生成；但進入時不顯示倒數，返回位置、客戶端操作與玩家資料仍有嚴重問題。 |
| 🛠 | 撤離與死亡回收 | 多人撤離點已正常生成，但撤離時不顯示倒數；死亡後重生與物資回收仍有問題。 |
| 🛠 | 獎勵箱 | 重複生成與貼圖破碎已修正。 |
| ✅ | 資訊顯示 | 彈藥／彈匣與交易貨幣餘額可正常顯示。 |

| 🛠 | 隊伍狀態 | 以其他隊伍進入時，玩家隊伍會被重置。 |
| 🛠 | 遠征裝備管理 | 未帶出的物品暫時放在據點儲存箱，最終保存方式仍在規劃。 |
| 🛠 | 敵人 | 基本 AI 可接受，但一般怪物仍會在突襲世界生成，敵人強度也仍待平衡。 |

| 🛠 | 現有槍械 | 單人功能正常，但素材與音效品質不一致。 |
| 🔴 | 補給與醫療物品 | 無法產生效果，使用時也有機率直接被打斷。 |

## 目前優先事項

1. 修正加油站往返時的倒數、返回位置、客戶端操作與玩家資料問題。
2. 修正多人死亡後無法重生，以及掉落物資異常回到玩家身上的問題。
3. 修正醫療物資無效與隨機中斷問題。
4. 阻止一般怪物在突襲世界生成，並修正跨隊伍進入時的隊伍重置。
5. 完成沙漠荒地的基礎地圖建置與後續平衡調整。

## 後續方向

- 將敵人生成與撤離點改為更容易調整的設定方式。
- 建置加油站室內地圖，並讓未來地圖能有多個撤離點。
- 重製槍械與物品素材；槍械改裝將改變外觀。
- 新增繁體／簡體中文切換選項。
