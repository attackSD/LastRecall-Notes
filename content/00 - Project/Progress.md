# LastRecall 目前進度

## 正在進行

**Desert Wasteland 沙漠荒地地圖建置**仍在非常前期。地形、探索路線、建築／場景與氛圍都正在從原型開始建立。

## 功能概覽

| 狀態  | 功能        | 目前情況                           |
| --- | --------- | ------------------------------ |
| ✅   | 玩家據點      | 可正常使用，目前沒有已知問題。                |
| ✅   | 加油站進出     | 可正常進出；室內地圖本身尚未開始建置。            |
| ✅   | 單人撤離與死亡回收 | 撤離點的功能、位置與視覺正常；死亡後可有一次取回物品的機會。 |
| ✅   | 資訊顯示      | 彈藥／彈匣與交易貨幣餘額可正常顯示。             |
| 🛠  | 傳送機與出發    | 單人正常；地圖選擇介面與方塊材質仍需調整。          |
| 🛠  | 遠征裝備管理    | 未帶出的物品暫時放在據點儲存箱，最終保存方式仍在規劃。    |
| 🛠  | 敵人        | 基本 AI 可接受，但生成方式、傷害與血量仍待調整。     |
| 🛠  | 搜刮箱子      | 可搜尋且會逐步揭露內容；仍缺音效與物資平衡。         |
| 🛠  | 回收商交易     | 收購與購買正常；商品內容與價格仍需平衡。           |
| 🛠  | 現有槍械      | 單人功能正常，但素材與音效品質不一致。            |
| 🔍  | 補給與醫療物品   | 最近機制更新後尚未重新測試。                 |

## 目前優先事項

1. 修正目前阻斷遊玩的地圖進入、死亡返回與重裝問題。
2. 完成沙漠荒地的基礎地圖建置。
3. 平衡敵人、箱內物資與回收商商品價格。
4. 改善傳送機的地圖選擇介面與方塊材質。
5. 安排多人流程測試。

## 後續方向

- 將敵人生成與撤離點改為更容易調整的設定方式。
- 建置加油站室內地圖，並讓未來地圖能有多個撤離點。
- 重製槍械與物品素材；槍械改裝將改變外觀。
- 新增繁體／簡體中文切換選項。
