# LastRecall 專案概覽

LastRecall 是一個以「準備、搜刮與撤離」為核心的 Terraria 模組。玩家會在基地整理裝備，進入 Raid 探索、戰鬥並帶回物資。

## 一次 Raid 會做什麼？

基地準備 → 出發 → 進入沙漠荒地 → 探索與戰鬥 → 搜刮物資 → 決定何時撤離 → 回到基地。

## 目前內容

- Desert Wasteland 沙漠荒地是目前主要的 Raid 地圖，正在用簡易版配置測試完整遊玩流程。
- 基地、傳送出發、撤離、死亡後處理、敵人、搜刮箱、商人與基本醫療物品都已建立不同程度的功能。
- M1911 是目前最完整的槍械；AK-47 與 MP5 可以遊玩基本流程，但仍使用暫用素材。
