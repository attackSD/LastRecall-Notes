# LastRecall 專案總覽

LastRecall 是一個以**準備、搜刮與撤離**為核心的 Terraria 模組。玩家從據點出發，帶著選定的裝備進入危險地帶；能否安全離開，決定一趟行動是否成功。

## 目前正在做什麼

目前的主要工作是建置第一張突襲地圖：**Desert Wasteland 沙漠荒地**。它仍處於非常前期，地形、探索路線、場景與氛圍都還在建立。

## 目前可以體驗到的基礎功能

- 玩家據點與進入地圖的傳送機。
- 敵人、可搜尋的箱子、撤離點與死亡後一次取回物品的機會。
- 可正常進出的加油站。
- 回收商的收購與購買功能。

這些功能的完成度並不相同；詳細狀態請看 [[00 - Project/Progress|目前進度]]。

## 專案目標

- 讓探索更深處有值得承擔的風險與收穫。
- 讓撤離成為每趟行動最重要的決定。
- 逐步建立一致的地圖、槍械、物品、音效與視覺風格。
