# LastRecall 更新紀錄

這裡以日期整理專案進度；同一天的內容會合併為一則更新。即時狀態請看 [[00 - Project/Progress|目前進度]]。

## 2026-08-05 — 多人測試與進入地圖流程更新

**已完成或確認：**

- 進入地圖時新增載入畫面，讓轉場過程更清楚；玩家進入 Raid 世界時會自動開啟 PvP，開服與進入時的 PvP 狀態提示刷頻也已修正。
- 客戶端可正常重新裝填，子彈也會正常扣除；隊伍準備與出發、箱子搜尋與現有物品／補給流程已確認正常。
- 玩家可成功進入地圖；先前地圖消失問題在近期測試中沒有重現。
- 多人撤離點與撤離倒數、加油站商店傳送門、加油站進入與離開倒數均已正常運作。
- 加油站先前錯誤返回主世界、無法操作、再次進入物品消失，以及客機卡在備份玩家資料的問題已修正。
- 無菌繃帶無法回復血量、醫療物資被中斷、敵人巡邏卡在高地或車上的問題已修正。
- 多人死亡後無法重生、突襲世界生成一般怪物、敵人子彈無法命中、敵人死亡後物資箱無法生成、獎勵箱重複生成與貼圖破碎問題均曾確認修正。

**本次發現、待處理的問題：**

- 進入 Raid 時，即使顯示同一隊伍，玩家仍會傷害隊友，也看不到隊友名稱。
- 進入 Raid 世界時，獎勵箱貼圖仍可能碎片化。
- 加油站返回時仍會先回到主世界，再進到沙漠荒地；反覆進出加油站可以刷新內部物資。
- 商人無法收購從 Raid 帶回的模組物品；交易介面旁常駐顯示泰拉幣列為後續改善建議。
- 敵人受背後攻擊後仍不會轉向，且子彈速度過慢、行為與玩家子彈不同。
- 死亡掉落物資可能回到玩家身上；使用其他隊伍進入時，隊伍可能被重置。

**持續確認：**

- 進入地圖載入畫面在多人流程中的表現。

詳細狀態請見 [[30 - Release/Known Issues|已知問題與測試]]，已確認修正的項目請見 [[30 - Release/Resolved Issues|已修正問題]]。
