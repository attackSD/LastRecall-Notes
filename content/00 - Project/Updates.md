# LastRecall 更新紀錄

這裡依日期整理專案進度；同一天的內容會合併為一則更新。即時狀態請看 [[00 - Project/Progress|目前進度]]。

## 2026-08-08 — Raid、加油站與 M1911 更新

**已完成或確認：**

- 加油站商店 Host 與遠端玩家雙向進出已通過多人測試；來回後 NPC、物資、撤離與死亡流程維持正常。
- M1911 手持位置偏移與左右翻轉問題已修正；自製槍聲已在實際遊戲確認播放正常。
- 空倉聲不再高速重複，已恢復正常武器使用節奏。
- Raid 返回主世界後可能無法移動或開啟選單的問題已修正，並通過 Host 與玩家回歸測試。
- Raid 死亡掉落恢復，以及撿回後防止舊掉落物重複生成，均已通過實際回歸測試。

**仍待完成：**

- 替換背景 Raid 區域生命週期的邊界情況已有實作修正，但仍等待最後的實際遊戲驗證。
- M1911 手持姿勢美術與槍聲混音、槍械陣容、物資與價格仍會繼續精修。

## 2026-08-07 — 準心系統與槍械製作持續

- 新增準心系統，不同槍械與改裝狀態可以使用不同的預設準心。
- 槍聲、槍械模型與配件持續同步建置與調整。

## 2026-08-06 — 敵人子彈修正與槍械改版

- 敵人子彈行為已調整為接近玩家子彈，並通過多人測試。
- 槍械音效、模型與配件改版開始進行；M1911、手槍彈藥、消音器與擴容彈匣已整合。
- 環境音效、空倉聲、消音射擊與後座力設定持續調整，數值平衡仍未完成。

## 2026-08-05 — 多人測試與地圖流程

- 載入畫面、PvP 自動切換、隊伍辨識、重新裝填、撤離點與倒數、死亡重生、掉落物處理及加油站商店傳送流程已通過相關測試。
- 加油站錯誤返回、無法操作、物品遺失、客機資料恢復卡住、反覆進出刷新物資等問題已修正。
- 無菌繃帶回血、醫療物品中斷、敵人巡邏與卡住、敵人命中、物資箱生成、獎勵箱重複與貼圖問題已確認修正。
- 敵人背後受擊後不轉向與 Recovery Broker 無法收購模組物品的問題已修正。

## 2026-08-04 — 專案筆記與方向整理

- 建立面向外部讀者的進度、更新紀錄與問題頁面。
- 整理既有功能、早期建置工作與未來方向；Desert Wasteland 仍是第一個主要 Raid。
- 整理據點補給、醫療站、槍械製作與改裝、護甲外觀、稀有度與未來地圖方向等尚未排程的構想。
