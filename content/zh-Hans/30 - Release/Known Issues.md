# LastRecall 已知问题与测试

## 仍需调整

| 项目 | 状态 | 说明 |
| ---- | ---- | ---- |
| 敌人强度 | 🛠 需要平衡 | 高阶敌人的伤害和血量仍需配合 Raid 风险调整。 |

## 目前表现稳定的项目

- Raid 进入、区域之间移动、撤离、死亡返回和掉落物回收都能运作。
- 从 Raid 返回主世界后无法移动或打开菜单的问题已经修正。
- 加油站商店的多人进出已经测试；来回后敌人、物资、撤离和死亡流程维持正常。
- M1911 持枪位置偏移、左右翻转、空仓声过快重复和自制枪声播放问题已完成相关测试。
- 无菌绷带可以正常回血，医疗物品也不会再异常中断。

详细修正记录请见 [[zh-Hans/30 - Release/Resolved Issues|已修正问题]]。

- 游戏内繁中和简中切换正常。
