# LastRecall 当前进度

## 当前重点

**Desert Wasteland 沙漠荒地**是目前主要的 Raid 地图。现在先用简易版地图布局测试一局 Raid 能否顺畅完成：基地准备、出发、探索、战斗、搜刮、撤离，再回到基地。

## 功能概况

| 状态 | 分类            | 当前情况                                                                                                                                                                            |
| ---- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ✅   | 基地与出发      | 基地、队伍准备和出发可以正常使用；地图选择界面和传送机材质仍会调整。                                                                                                                |
| ✅   | Raid 地图与移动 | 可以进入沙漠荒地和加油站商店；多人游玩时，地图之间的进出与返回也能正常完成。                                                                                                        |
| ✅   | 撤离与死亡      | 撤离点、倒计时、死亡后重生、掉落物回收和返回基地都能正常运作。                                                                                                                      |
| ✅   | 多人和队伍      | 不同队伍可以一起进入 Raid；同队玩家不会互相伤害，也能看见队友名称。                                                                                                                 |
| ✅   | 敌人            | 基本遭遇、感知、远程攻击和死亡掉落已经建立；敌人的强度、数量与出现位置仍需配合 Raid 节奏调整。                                                                                      |
| 🛠   | 搜刮与物资      | 箱子可以搜索并逐步揭露物品；搜刮音效、箱内物资和奖励内容仍需调整。                                                                                                                  |
| 🛠   | 商人和信息      | 可以把符合条件的 Raid 物资卖给回收商换取泰拉币，再用泰拉币购买现有枪械、弹药与配件；交易时可以看到目前持有的泰拉币，商品内容、价格与界面细节仍需调整。                              |
| 🛠   | 枪械与战斗反馈  | M1911、使用临时素材的 AK-47 和 MP5 都能正常射击与装填。命中、击杀、枪口效果、空仓状态与贴墙射击已经完成多人实际确认；正式素材、更多配件、枪声内容、平衡和特殊枪械操作仍会继续制作。 |
| ✅   | 医疗与语言      | Raid 中不会自然回血，医疗用品需要花一段时间完成治疗；无菌绷带和其他医疗用品可以正常使用，繁中／简中切换已完成。                                                                     |
| 🛠   | 装备管理        | 出发前可以选择带入 Raid 的装备；没有带出的背包物品会暂时保留，返回基地后可以从自己的回收箱取回。目前这仍是暂行的装备保管方式。                                                      |

## 当前优先事项

1. 用简易版沙漠荒地布局测试完整 Raid 流程，包括出生区、开放与室内战斗空间、物资和敌人位置，以及撤离路线。
2. 调整地图大小、移动距离、探索节奏、战斗间隔、风险与回报，让一局游戏更完整。
3. 在地图制作以外，继续处理枪械素材、音效、配件与平衡，并补完地下和隧道等不同环境下的枪声。

## 后续方向

- 让每张地图的敌人生成与撤离点更容易调整，并支持多个撤离点。
- 继续扩展加油站商店的场景、探索内容与美术。
- 未来在基地加入枪械改装台，让玩家安装配件并直接看到枪械外观变化。
