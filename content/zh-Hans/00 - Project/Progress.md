# LastRecall 当前进度

## 当前重点

**Desert Wasteland 沙漠荒地**是目前主要的 Raid 地图。现在先用简易版地图布局测试一局 Raid 能否顺畅完成：基地准备、出发、探索、战斗、搜刮、撤离，再回到基地。

## 功能概况

| 状态 | 分类 | 当前情况 |
| ---- | ---- | ---- |
| ✅ | 基地与出发 | 基地、队伍准备和出发可以正常使用；地图选择界面和传送机材质仍会调整。 |
| ✅ | Raid 地图与移动 | 可以进入沙漠荒地和加油站商店，地图之间的进出、加载与返回流程已通过多人测试。 |
| ✅ | 撤离与死亡 | 撤离点、倒计时、死亡后重生、掉落物回收和返回基地都能正常运作，已确认不会重复生成旧掉落物。 |
| ✅ | 多人和队伍 | 不同队伍可以一起进入 Raid；同队玩家不会互相伤害，也能看见队友名称。 |
| ✅ | 敌人 | 基本遭遇、感知、远程攻击和死亡掉落已经建立；巡逻和转向问题已修正，敌人强度仍需平衡。 |
| 🛠 | 搜刮与物资 | 箱子可以搜索并逐步揭露物品；搜刮音效、箱内物资和奖励内容仍需调整。 |
| 🛠 | 商人和信息 | 可以交易并收购从 Raid 带回的模组物品；商品价格、内容和常驻货币显示仍需改善。 |
| 🛠 | 枪械与战斗反馈 | M1911、AK-47 临时素材和 MP5 临时素材都能使用基本射击流程。命中、血肉音效、枪口火光烟雾、贴墙射击和初版致死反馈已经加入；多人游玩时的枪口效果、致死反馈辨识度、音效、配件、素材和平衡仍在调整。 |
| ✅ | 医疗与语言 | 无菌绷带和医疗物品使用问题已修正；繁中／简中切换已完成。 |
| 🛠 | 装备管理 | 没有带出的物品目前暂存在基地箱子里，之后的保存方式仍在规划。 |

## 当前优先事项

1. 用简易版沙漠荒地布局测试完整 Raid 流程，包括出生区、开放与室内战斗空间、物资和敌人位置，以及撤离路线。
2. 调整地图大小、移动距离、探索节奏、战斗间隔、风险与回报，让一局游戏更完整。
3. 继续处理枪械素材、音效、配件、平衡，以及多人枪口效果和致死反馈的后续测试。

## 后续方向

- 让每张地图的敌人生成与撤离点更容易调整，并支持多个撤离点。
- 继续扩展加油站商店的场景、探索内容与美术。
- 未来在基地加入枪械改装台，让玩家安装配件并直接看到枪械外观变化。
