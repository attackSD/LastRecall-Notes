# LastRecall 项目概览

LastRecall 是一个以“准备、搜刮与撤离”为核心的 Terraria 模组。玩家会在基地整理装备，进入 Raid 探索、战斗并带回物资。

## 一次 Raid 会做什么？

基地准备 → 出发 → 进入沙漠荒地 → 探索与战斗 → 搜刮物资 → 决定何时撤离 → 返回基地。

## 当前内容

- Desert Wasteland 沙漠荒地是目前主要的 Raid 地图，正在用简易版布局测试完整游玩流程。
- 基地、传送出发、撤离、死亡后的处理、敌人、可搜索箱子、商人和基础医疗物品都已建立不同程度的功能。
- M1911 是目前最完整的枪械；AK-47 和 MP5 可以游玩基本流程，但仍使用临时素材。
