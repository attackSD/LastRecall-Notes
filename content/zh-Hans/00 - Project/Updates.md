# LastRecall 更新记录

这里按日期整理项目进度；同一天的内容会合并为一条更新。即时状态请查看 [[zh-Hans/00 - Project/Progress|当前进度]]。

## 2026-08-08 — Raid、加油站与 M1911 更新

**已完成或确认：**

- 加油站商店 Host 与远程玩家双向进出已通过多人测试；往返后 NPC、物资、撤离与死亡流程保持正常。
- M1911 持枪位置偏移与左右翻转问题已修复；自制枪声已在实际游戏中确认正常播放。
- 空仓声不再高速重复，已恢复正常武器使用节奏。
- Raid 返回主世界后可能无法移动或打开菜单的问题已修复，并通过 Host 与玩家回归测试。
- Raid 死亡掉落恢复，以及拾回后防止旧掉落物重复生成，均已通过实际回归测试。

**仍待完成：**

- 替换背景 Raid 区域生命周期的边界情况已有实现修正，但仍等待最后的实际游戏验证。
- M1911 持枪姿势美术与枪声混音、枪械阵容、物资与价格仍会继续优化。

## 2026-08-07 — 准星系统与枪械制作继续

- 新增准星系统，不同枪械与改装状态可以使用不同的默认准星。
- 枪声、枪械模型与配件继续同步制作与调整。

## 2026-08-06 — 敌人子弹修正与枪械改版

- 敌人子弹行为已调整为接近玩家子弹，并通过多人测试。
- 枪械音效、模型与配件改版开始进行；M1911、手枪弹药、消音器与扩容弹匣已经整合。
- 环境音效、空仓声、消音射击与后坐力设置继续调整，数值平衡仍未完成。

## 2026-08-05 — 多人测试与地图流程

- 加载画面、PvP 自动切换、队伍识别、重新装填、撤离点与倒计时、死亡重生、掉落物处理及加油站商店传送流程已通过相关测试。
- 加油站错误返回、无法操作、物品丢失、客户端数据恢复卡住、反复进出刷新物资等问题已修复。
- 无菌绷带回血、医疗物品中断、敌人巡逻与卡住、敌人命中、物资箱生成、奖励箱重复与贴图问题已确认修复。
- 敌人受到背后攻击后不转身，以及 Recovery Broker 无法收购模组物品的问题已修复。

## 2026-08-04 — 项目笔记与方向整理

- 建立面向外部读者的进度、更新记录与问题页面。
- 整理现有功能、早期制作工作与未来方向；Desert Wasteland 仍是第一个主要 Raid。
- 整理据点补给、医疗站、枪械制作与改装、护甲外观、稀有度与未来地图方向等尚未排期的构想。
